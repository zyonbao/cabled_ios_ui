## Purpose

Web 控制台剪贴板交互 UI——提供设置/读取设备剪贴板的入口与弹窗，并支持把读取内容复制到本机。

## Requirements

### Requirement: 设置剪贴板入口与弹窗

slide6 桌面端与 web 端 SHALL 各提供「设置剪贴板」按钮；点击后弹出一个包含文本输入区与「确认 / 取消」两个按钮的输入窗口。仅在设备已连接时该按钮可用。

#### Scenario: 确认写入剪贴板

- **WHEN** 用户在设置剪贴板弹窗输入文本并点击「确认」
- **THEN** 调用剪贴板写入能力（slide6 经 `toolkit_api.set_pasteboard`，web 经 `/api/set_pasteboard`）把内容写入目标设备剪贴板，并关闭弹窗

#### Scenario: 取消不写入

- **WHEN** 用户在设置剪贴板弹窗点击「取消」
- **THEN** 关闭弹窗，不发起任何写入请求

#### Scenario: 设置成功/失败提示

- **WHEN** 确认写入后底层返回成功或失败
- **THEN** UI SHALL 分别给出「已设置」或失败原因的状态提示

### Requirement: 读取剪贴板入口与展示窗口

slide6 桌面端与 web 端 SHALL 各提供「读取剪贴板」按钮；点击后读取设备当前剪贴板并弹出文本展示窗口。仅在设备已连接时该按钮可用。

#### Scenario: 展示文本剪贴板

- **WHEN** 用户点击「读取剪贴板」且设备剪贴板为文本内容
- **THEN** 弹出窗口展示该文本内容

#### Scenario: 非文本内容提示

- **WHEN** 读取结果 `isText` 为 false（非文本内容）
- **THEN** 弹窗 SHALL 提示「剪贴板为空或为非文本内容」且不提供复制操作

#### Scenario: 读取成功/失败提示

- **WHEN** 读取剪贴板底层返回成功或失败
- **THEN** UI SHALL 给出「已读取」或失败原因的状态提示

### Requirement: 读取展示窗口可复制到本机

slide6 桌面端与 web 端读取剪贴板展示窗口（仅文本态）SHALL 提供「复制到本机」按钮，点击把展示内容写入运行控制台的主机剪贴板，并给出「已复制」提示。

#### Scenario: 复制到本机

- **WHEN** 读取展示窗口为文本态且用户点击「复制到本机」
- **THEN** 把文本写入主机剪贴板并提示「已复制到本机剪贴板」

### Requirement: 读取展示窗口允许复制

slide6 桌面端读取剪贴板展示窗口 SHALL 允许用户用鼠标选中并复制文本内容（仅当内容为文本时）；web 端允许选中复制为可选项，可不强制实现。

#### Scenario: slide6 文本可选中复制

- **WHEN** slide6 展示窗口显示的是文本内容
- **THEN** 用户可用鼠标选中并复制其中文本

#### Scenario: 非文本时禁止复制

- **WHEN** 展示窗口因非文本内容而提示「非文本内容」
- **THEN** 不提供可复制的文本区域

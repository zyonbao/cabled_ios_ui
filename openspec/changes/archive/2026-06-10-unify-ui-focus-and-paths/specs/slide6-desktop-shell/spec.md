## ADDED Requirements

### Requirement: Tab 与子页面切换不自动聚焦输入框

切换到任意侧边 Tab，或进入任意子页面 / 对话框时，应用 MUST NOT 自动将键盘焦点落到输入框（如过滤框、路径框）。焦点应保持中性，由用户主动点选输入框后再进入编辑。唯一例外：键鼠操作打开键盘输入捕获时，MUST 自动聚焦捕获输入框以便立即接收按键。

#### Scenario: 切换到含输入框的 Tab

- **WHEN** 用户切换到「设备信息 / App 列表 / Crash 报告 / 系统日志」等含输入框的 Tab
- **THEN** 不自动聚焦任何输入框

#### Scenario: 进入子页面 / 对话框

- **WHEN** 用户打开某个含输入框的子页面或对话框
- **THEN** 不自动聚焦其中的输入框

#### Scenario: 键盘捕获例外

- **WHEN** 用户在键鼠操作中打开键盘输入捕获
- **THEN** 自动聚焦捕获输入框（保持现状）
